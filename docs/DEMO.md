# Demo Boundary

This is a testnet/demo control plane, not a production custody product. Demonstrable supported flows are wallet connection, SIWE authentication, balance reads, native transfers, reviewed contract deployment preparation, deterministic workflow preparation, transaction integrity verification, and lifecycle inspection.

Use the Phase 9 proof page only with a healthy Studionet validator set. Record the EVM hash, consensus ID, contract address, canonical state reads, and final settlement evidence. Never call a transaction successful merely because it was broadcast or mined.
